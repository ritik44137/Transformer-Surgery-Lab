# Comparison artifacts

This directory holds **derived** comparison outputs generated by `scripts/compare_runs.py`.

## Source of truth

Individual run directories under `runs/<run_id>/` are the source of truth. Files here are aggregated views for CLI inspection and dashboard loading.

## Generation

```bash
python scripts/compare_runs.py --runs runs/baseline runs/rmsnorm_swap ...
```

## Expected files (after Phase 6)

- `comparison.json` — compact metric bundle for all selected runs
- `comparison.csv` — tabular export for spreadsheets
